# Plus backlog

Opt-in quality-of-life changes for the "Plus" side of WrathPlus, in the spirit of modern classic+
servers. The default stays stock 3.3.5. Each entry here is stock-correct as the client behaves
today, so none of them is a bug. They will ship as options through addon packaging. Nothing here is
scheduled yet.

| Idea | Stock 3.3.5 behaviour | Source |
|---|---|---|
| Item tooltips always compare with the equipped item(s) | Comparison plates only while Shift is held | Playtest 2026-10-24 |
| Stat-change summary on comparison ("If you replace this item…") | Absent (added in Cataclysm) | Playtest 2026-10-24 |
| Sell price shown on every item tooltip | Shown only while a vendor window is open | Playtest 2026-10-24 |
